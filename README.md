### 2. 계정별 상세 기능

| 역할 (Role) | 기능 |
| :--- | :--- | :--- | :--- | :--- |
| **최고 관리자** | `대시보드' - 전체 평가대상, 평가 완료율, 전사 평균점수, 팀 보너스 현황, 팀별 평균점수, 팀별 등급분포, 평가 항목별 팀 역량 확인 가능   | '팀 관리' - 팀과 담당 매니저 배정 | '사원관리' - 사원정보 수정, 추가, 삭제 가능 | '평가 항목 관리' | '점수 및 보너스 관리' - 팀보너스 적용 가능|
| **팀 매니저** | `팀원 평가` - 평가 항목 별 평가, 피드백(객관, 주관 평가 모두 가능), 수정 가능 | 
| **일반 직원** | `내 평가 결과 및 피드백` - 최종점수, 등급 달성 로드맵, 매니저 피드백 확인 가능 | 평가 결과 출력 및 다운로드 가능 |
