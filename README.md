### 2. 계정별 상세 기능

| 역할 | 메뉴 / 기능 | 상세 설명 |
| :--- | :--- | :--- |
| **최고 관리자** | **대시보드** | 전체 평가 대상, 평가 완료율, 전사 평균 점수, 팀 보너스 현황, 팀별 평균 점수, 팀별 등급 분포, 평가 항목별 팀 역량 조회 |
| | **팀 관리** | 부서/팀 생성 및 담당 매니저 배정 |
| | **사원 관리** | 사원 정보 추가, 수정, 삭제(CRUD) |
| | **평가 항목 관리** | 평가 지표 및 세부 평가 항목 설정/관리 |
| | **점수 및 보너스 관리** | 최종 점수 산출 및 팀별 보너스 설정/적용 |
| **팀 매니저** | **팀원 평가** | 항목별 평가 수행 및 피드백 작성 (객관식 점수 및 주관식 코멘트 지원, 제출 후 수정 가능) |
| **일반 직원** | **내 평가 결과 조회** | 최종 점수, 등급 달성 로드맵, 매니저 피드백 열람 |
| | **결과 출력 / 저장** | 평가 결과 보고서 출력 및 다운로드 |
