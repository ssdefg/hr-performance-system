# 03. 사용자 인증 및 권한 체계 명세 (Authentication & RBAC)

## 1. 사번 기반 인증 개요
- 기본 사용자 식별자: `employee_id` (사번, CharField unique)
- JWT 토큰 기반 무상태(Stateless) 인증 (SimpleJWT)
- 비밀번호 암호화: Django PBKDF2 해싱

## 2. 역할별 권한 매트릭스 (RBAC)
| 기능 / 엔드포인트 | Admin (관리자) | Manager (매니저) | Employee (직원) |
| :--- | :---: | :---: | :---: |
| 팀 생성 / 수정 / 삭제 | ✅ 전체 | ❌ 불가 | ❌ 불가 |
| 사원 생성 / 수정 / 삭제 | ✅ 전체 | ❌ 불가 | ❌ 불가 |
| 평가 항목 및 가중치 관리 | ✅ 전체 | ❌ 불가 | ❌ 불가 |
| 팀원 평가서 작성 / 임시저장 | ❌ 불가 | ✅ 소속 팀원만 | ❌ 불가 |
| 팀원 평가서 최종 제출 | ❌ 불가 | ✅ 소속 팀원만 | ❌ 불가 |
| 팀 보너스 일괄 입력 | ✅ 전체 | ❌ 불가 | ❌ 불가 |
| 전사 KPI 및 모니터링 | ✅ 전체 | ❌ 불가 | ❌ 불가 |
| CSV 데이터 내보내기 | ✅ 전체 | ❌ 불가 | ❌ 불가 |
| 본인 평가 결과 열람 | ✅ 조회 가능 | ✅ 조회 가능 | ✅ 본인만 |

## 3. 기본 관리자 계정 시딩
- 시스템 최초 구동 시 `post_migrate` 시그널로 자동 생성:
  - **사번**: `ADMIN`
  - **성명**: `ADMIN`
  - **비밀번호**: `admin1234!`
  - **역할**: `ADMIN` (`is_staff=True`, `is_superuser=True`)
