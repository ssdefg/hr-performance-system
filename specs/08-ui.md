# 08. UI/UX 디자인 시스템 및 화면 컴포넌트 명세 (Design System & UI Components)

## 1. 개요 및 디자인 철학

본 문서는 **HR Performance Review System**의 UI/UX 디자인 시스템, 색상 체계, 공통 레이아웃, 컴포넌트 구조 및 각 사용자 역할별(Admin, Manager, Employee) 화면 상세를 정의합니다.
단순한 템플릿 수준을 넘어 **엔터프라이즈 B2B SaaS(HRMS)** 환경에 최적화된 고품질의 직관적이고 세련된 인터페이스를 구축하는 것을 목표로 합니다.

---

## 2. 디자인 시스템 및 테마 가이드

### 2.1 색상 팔레트 & 톤앤매너
- **페이지 전체 배경**: `#f8fafc` (Slate-50 / Soft Cool Gray)
- **카드 및 컨테이너 배경**: `#ffffff` (Pure White)
- **테두리 및 경계선**: `#e2e8f0` (Slate-200, `1px solid #e2e8f0`)
- **텍스트 컬러**:
  - Primary: `#0f172a` (Slate-900 / 딥 다크 네이비)
  - Secondary / Muted: `#64748b` (Slate-500)
  - Light Muted: `#94a3b8` (Slate-400)
- **브랜드 및 액션 컬러**:
  - Primary Blue: `#206bc4` (Tabler Azure Primary) / Hover: `#1a569d`
  - Success Green: `#2fb344` (Badge BG: `#dcf6e4`, Text: `#1b7a2d`)
  - Warning Amber: `#f59f00` (Badge BG: `#fff0cc`, Text: `#9e6000`)
  - Danger Red: `#d63939` (Badge BG: `#fce3e3`, Text: `#9b1c1c`)
  - Capped Badge: `#4263eb` (Indigo) / `#e0e7ff` (BG: Indigo-subtle)

### 2.2 공통 컨테이너 및 쉐도우 규칙
- **카드 스타일 (`.card-enterprise`)**:
  ```css
  background-color: #ffffff;
  border: 1px solid #e2e8f0;
  border-radius: 12px; /* rounded-3 */
  box-shadow: 0 1px 3px 0 rgba(0, 0, 0, 0.05), 0 1px 2px -1px rgba(0, 0, 0, 0.05); /* shadow-sm */
  ```

- **인터랙티브 요소 호버**: 카드 호버 시 `box-shadow: 0 4px 6px -1px rgba(0,0,0,0.07)`로 부드러운 강조.

## 3. 공통 레이아웃 아키텍처 (`AppLayout.vue`)

```
+-----------------------------------------------------------------------------------+
| [Logo] HR Review   |  Global Search [ 🔍 사원, 팀 검색... ]  |  Cycle: 2026-Q1 [👤] | (Top Header)
+--------------------+--------------------------------------------------------------+
| 📊 대시보드         |                                                              |
| 🏢 팀 관리          |                                                              |
| 👥 사원 관리        |                    메인 콘텐츠 뷰 영역                       |
| ⚖️ 평가 항목       |                 (Router View / Card Flow)                    |
| 📈 점수/보너스      |                                                              |
| ⚙️ 로그아웃         |                                                              |
| (Slim Sidebar)     |                                                              |
+--------------------+--------------------------------------------------------------+
```

### 3.1 좌측 슬림 사이드바 (Slim Navigation)
- 너비: 고정 240px (반응형 모바일 시 햄버거 토글 드로어)
- 구성:
  - 상단: 서비스 로고 (`HR Review Pro` + 엔터프라이즈 뱃지)
  - 네비게이션 메뉴 (권한별 분기 렌더링):
    - **Admin**: 대시보드(통계), 팀 관리, 사원 관리, 평가 항목 관리, 점수/보너스 일괄 관리
    - **Manager**: 팀원 다면 평가, 평가 진행 현황
    - **Employee**: 내 평가 결과 조회
  - 하단: 사용자 간이 프로필 칩 및 로그아웃 버튼

### 3.2 상단 글로벌 헤더 (Global Navbar)
- 높이: 64px, `bg-white`, 하단 경계선 `border-bottom: 1px solid #e2e8f0`
- 구성:
  - 좌측: 현재 페이지 브레드크럼 (Breadcrumb: `홈 > 평가 관리 > 점수/보너스`)
  - 중앙/우측:
    - 전사 평가 주기 인디케이터 배지: `2026년 상반기 정기평가 (진행중)`
    - 통합 검색 인풋 (Admin 전용: 사번/이름/팀명 퀵 필터)
    - 사용자 아바타 (이니셜 기반 32px 원형 아바타) + 성명 + 역할 배지

## 4. 핵심 화면 컴포넌트 상세 명세

### 4.1 관리자 대시보드 및 통계 (`AdminDashboardView.vue`)

#### (1) 상단 4열 KPI 요약 카드 그리드
```
+-------------------+ +-------------------+ +-------------------+ +-------------------+
| 👥 전체 평가 대상  | | 📈 평가 완료율    | | 🎯 전사 평균 점수 | | 🎁 팀 보너스 현황 |
|      128 명       | |      84.5 %       | |      86.4 점      | |    5 / 6 개 팀    |
| (전년 대비 +12명)  | | [========>  ] 84% | | (상한 도달: 8명)  | | (미부여 1개 팀)   |
+-------------------+ +-------------------+ +-------------------+ +-------------------+
```
- **KPI Card 1 (전체 인원수)**: 전체 활성 평가 대상 사원수 집계
- **KPI Card 2 (평가 완료율)**: `(제출 완료된 평가수 / 전체 대상자) * 100`, 슬림 프로그레스 바 포함
- **KPI Card 3 (전사 평균 점수)**: 제출 완료된 최종 점수의 산술 평균, 상한 도달 인원 서브 텍스트
- **KPI Card 4 (보너스 현황)**: 보너스가 부여된 팀 수 / 전체 팀 수 비율

#### (2) 점수 및 보너스 관리 인라인 툴바 (`ScoreBonusToolbar.vue`)
- 단일 Flex Row 정렬 (`d-flex align-items-center justify-content-between gap-3 flex-wrap`):
  - `[팀 필터 드롭다운]` (전체 팀, 개발팀, 기획팀, 디자인팀 등)
  - `[보너스 점수 입력 폼]` (0.0 ~ 10.0 Step 0.5 Number Input)
  - `[팀 전체 적용 버튼]` (`btn-primary` + Sparkles 아이콘, 클릭 시 재확인 컨펌 모달)
  - `[CSV 다운로드 버튼]` (`btn-outline-secondary` + Download 아이콘, UTF-8 BOM 인코딩 내보내기)

#### (3) 데이터 그리드 테이블 컴포넌트 (`ScoreDataTable.vue`)
- **테이블 헤더**:
  - `[선택]` | `사원 정보` | `소속 팀` | `평가 상태` | `개인 점수` | `팀 보너스` | `최종 점수` | `상한(Cap)`
- **행(Row) 디자인**:
  - **사원 정보**: 원형 이니셜 아바타 칩 (`avatar avatar-sm bg-blue-lt`) + 성명 (굵게) + 하단 사번 (`#64748b`)
  - **소속 팀**: 텍스트 뱃지
  - **평가 상태**: `제출 완료 (초록)` / `임시 저장 (주황)` / `미작성 (회색)`
  - **팀 보너스**: 캡슐 배지 (`badge bg-success-subtle text-success border border-success-subtle`, 예: `+5.0점`)
  - **최종 점수**: 대형 볼드 폰트 (`fw-bold text-dark`, 예: `87.0점`)
  - **상한 라벨**: 최종 점수가 100점에 도달/초과 제한된 경우 `badge bg-indigo-subtle text-indigo`의 `(상한)` 라벨 표시

### 4.2 매니저 평가 작성 폼 (`EvaluationFormView.vue`)

#### (1) 상단 피평가자 프로필 헤더
- 피평가자 성명, 사번, 소속 팀, 담당 업무 요약 표시
- 평가 진행 상태 배지 (`DRAFT` / `SUBMITTED`)

#### (2) 평가 항목 리스트 및 1~5점 세그먼트 버튼 그룹 (`SegmentButtonGroup.vue`)
- 각 평가 항목별 카드:
  - 항목명 (예: `1. 직무 수행 전문성 및 목표 달성도`) + 가중치 배지 (`가중치 40%`)
  - 세부 평가 가이드라인 설명문 (Muted text)
  - **1~5점 인터랙티브 세그먼트 버튼 그룹**:
    ```
    [ 1 매우미흡 ]  [ 2 미흡 ]  [ 3 보통 ]  [ 4 우수 ]  [ 5 매우우수 ]
    ```
    - 비활성: `btn btn-outline-secondary`
    - 선택 활성화: `btn btn-primary shadow-sm fw-bold`
    - 클릭 시 즉시 실시간 점수 환산 이벤트 발생

#### (3) 실시간 점수 환산 프리뷰 사이드 패널 (Live Score Preview)
- 화면 우측 고정 카드 (모바일 시 하단 고정 바):
  - **실시간 항목별 환산 점수 리스트**:
    - 항목 1 (가중치 40%): `4점 선택 -> 32.0 / 40점`
    - 항목 2 (가중치 30%): `5점 선택 -> 30.0 / 30점`
    - 항목 3 (가중치 30%): `3점 선택 -> 18.0 / 30점`
  - **예상 개인 환산 점수**: `80.0 / 100점` (대형 인디케이터)
  - **진행률 프로그레스**: `3 / 3 항목 입력 완료 (100%)`
  - **하단 액션 버튼**:
    - `[임시 저장]` (`btn-outline-primary`, 언제든 저장 가능)
    - `[최종 제출]` (`btn-primary`, 모든 항목 입력 시 활성화, 제출 시 잠금 안내 모달)

---

### 4.3 직원 전용 평가 결과 조회 (`MyEvaluationView.vue`)

#### (1) 최종 점수 인포그래픽 카드
- 거대 폰트의 최종 점수 (`92.5점`)
- 세부 칩 구성: `개인 평가 87.5점` + `팀 보너스 +5.0점` = `최종 92.5점`
- 상한 적용 시: `(최대 상한 100.0점 적용됨)` 안내 배지

#### (2) 평가 항목별 환산 내역 브레이크다운 테이블
- 항목명, 항목 가중치(%), 부여 척도(1~5점), 획득 점수(환산점), 항목별 설명

## 5. UI 인터랙션 및 반응형 가이드

1. **로딩 및 스켈레톤 UI**:
   - 데이터 로딩 중에는 단순 스피너 대신 Tabler 스켈레톤 플레이스홀더(`placeholder placeholder-glow`)를 적용하여 깜빡임 최소화.
2. **토스트 알림 (Toast Notifications)**:
   - 임시 저장 성공: `우측 상단 초록색 토스트 (임시 저장되었습니다.)`
   - 유효성 에러 / 가중치 불일치: `우측 상단 붉은색 토스트 (에러 메시지)`
3. **제출 잠금(Lock) 확인 모달**:
   - 최종 제출 클릭 시 `Modal` 팝업을 통해 "제출 후에는 평가 점수를 수정할 수 없습니다. 계속하시겠습니까?" 컨펌 절차 필수 수행.
